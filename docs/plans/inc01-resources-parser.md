## The missing boundary

The coherent source has the canonical A51 component `ProjectNativeResourcePage` (with `ProjectNativeResource`,
`…Mine`, `…Host` and `…Qualification`) and its generated TypeScript type. It has **no** validator and no parser:
- `scripts/generate-validators.ts` lists its exports explicitly, and `ProjectNativeResourcePage` is not among them;
- `src/validate.ts` exports no A51 parser.

The approved read-only Resources adapter needs the canonical parser, so a handwritten shape is not an option. This is a
prerequisite for that next consumer, not a fault in the current catalog, which has no reader yet. The members read
(`memberRead`, P02) already exists and is not touched.

## Behaviour (the existing reader policy, not a new one)

- The validator is compiled ahead of time, standalone, from the actual canonical schema, with the generator's existing
  options: strict, all formats, no coercion, no defaults, `removeAdditional: true`. It runs without Ajv or eval in a
  browser.
- **Tolerant reader.** A property the schema does not list is **dropped**, at any depth, not refused
  (`docs/plans/tolerant-readers.md`). This parser therefore does not promise strict rejection of unknown fields. The
  earlier adapter proposal's wording that it would is corrected in the handoff. Because Ajv drops in place, tests use
  fresh copies.
- **Still refused (`ContractViolation`):**
  - a missing required field or a wrong type;
  - an enum value the schema does not list;
  - an id that is not a UUID, or a time that is not a `date-time`;
  - a label over 200 characters;
  - `secondsSinceSeen` that is negative, fractional or over the safe-integer bound;
  - more than 200 resources, more than 3 operations or more than 8 `notReported` entries.
- **Not checked here; the adapter's job:** relational meaning the schema does not express. That is the owner and
  viewer agreement (`isYou` against `mine`), operations being a set in a fixed order, `nextCursor` against `complete`,
  and qualification state against its times. No privacy or relational guarantee is claimed from this schema.
