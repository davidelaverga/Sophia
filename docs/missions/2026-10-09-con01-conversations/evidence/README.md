# Evidence templates, not evidence of execution

[acceptance.json](acceptance.json) contains the required checklist, all `not_run`. [episode.example.json](episode.example.json) is synthetic seed material for local tests. Neither file is a production API response, membership grant, provider result or release approval.

Implementers should copy the checklist into their actual restricted/normalized evidence process, record results under the candidate and preserve original not-run template bytes in this pack. Do not fabricate actual IDs from these readable examples.
