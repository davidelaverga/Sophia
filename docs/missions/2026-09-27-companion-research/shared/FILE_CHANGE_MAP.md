## Testing and operational ownership

Claude authors tests and migration/runbook source in the same PR as the behavior. Codex executes assigned isolated tests or actual hosted batches and returns evidence; it does not rewrite shared code paths while Claude uses them. SQL/application permissions, new format read compatibility, secret absence in renderer, source revocation and old/new logs are tested at their real boundaries, not only mocked UI components.

Use targeted test modules alongside the existing suites. Exact new test filenames are implementation choices; preserve the mission's named acceptance IDs in the evidence table so a renamed file cannot make a requirement disappear.
