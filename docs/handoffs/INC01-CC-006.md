## Outcome

`GET /api/v1/projects/{projectId}/native-resources?after=<uuid>`, always served (whatever new owner-runner work admits),
`no-store`, read in one REPEATABLE READ READ ONLY transaction as the verified actor. It returns
`ProjectNativeResourcePage`:
- `observedAt`: one database instant, which judges every expiry and age;
- `resources`: at most 200, by id;
- `nextCursor` (the last id, only when a 201st row exists) and `complete`;
- `notReported`: sessions, assignments, models, efforts, capacity, readiness, sign-in and accounts. These are never
  returned as empty lists.

**Each resource:**
- `id`;
- `tool` (`codex` or `claude`; never the `dsh` runtime);
- `state` (`active`, `revoked` or `needs_connection`);
- `owner`: id, `label` (`actor_label`, null if unknown), `isYou` and `isMember`.

**The owner alone also reads `mine`:**
- the connection's state and an expired boolean;
- the connection's one live host: state, `helloOk`, a `helloConflict` boolean, `lastSeenAt`, and `secondsSinceSeen`,
  which is null for a missing time or one later than `observedAt`;
- the recorded qualification: 0092's unrevoked record, else the latest by `(qualified_at, id)`. Its state is `none`,
  `current`, `expired`, `revoked`, `stale` or `not_applicable`, with its operations, `qualifiedAt` and `expiresAt`.

`current` requires all of these: unrevoked, unexpired, the resource active at the same revision, the connection
linked, unexpired and the same at the same revision, and the owner an active admin or editor. It is recorded operator
evidence, not readiness or a promise that Stop works. A47 admission and dispatch are unchanged.

**Errors.**
- A nonmember and a missing project: 404 `not_found`, alike.
- Malformed ids, cursors or extra query fields: 422.
- No 0097: 503 `projection_unavailable`.
- No token: 401.

**Ids.** Path and cursor ids are `format: uuid` in the contract and the route (any case, `urn:uuid:`), then read in one
lowercase spelling; the global `UUID_PATTERN` is unchanged.

**The live host.** It relies on 0096's `owner_hosts_one_live_per_connection` (the erratum), with no duplicate-host
machinery.

**SQL.** One `SECURITY DEFINER` reader, `EXECUTE` to `sophia_api` only. It checks membership first, and its owner-only
helpers are executable by no application role and run only for the owner's rows. It returns states and booleans
only: no label, path, credential, account key, environment, profile, journal, capability or conflict text.

## r2: full RFC 3339 times, whatever the session time zone (CC006-R1-F01)

One signed development child of `13c9096e` (study INC01-CC-006-r1-BOUNDED-SOURCE-STUDY-001). Exactly six paths: the
0097 migration and its SQL test, the persistence and API DB tests, [the plan](../plans/project-native-resources.md)
("r2", written before code) and this handoff. A51, every generated output, `app.ts`, `index.ts`, the reader and the
route are byte-exact at `13c9096e`. No contract change was needed.

### Outcome

- **The defect.** r1 judged a time representable by its year in the caller's session zone. But jsonb renders a
  `timestamptz` in that zone with its historical offset, which can carry seconds. So a legal 1900 time read by an API
  session in `Asia/Kathmandu` was `1900-01-01T05:41:16+05:41:16`, and the owner's page answered 503. Here
  `Europe/Amsterdam` and `Africa/Monrovia` do the same.
- **The fix.** The reader, the only executable entry point, now runs with a function-level `SET TimeZone = 'UTC'`.
  - Every outward time is built inside it: `observedAt`, `qualifiedAt`, `expiresAt` and `lastSeenAt`. Each is
    `YYYY-MM-DDThh:mm:ss[.ffffff]+00:00` whatever the caller's zone or DateStyle.
  - PostgreSQL restores the caller's setting when the function returns, so the session is unchanged; the SQL and DB
    tests assert this.
  - The r1 year guard now judges exactly the UTC string written. UTC year-1 and year-9999 times are read as themselves
    in every zone; New York and Kiritimati no longer turn them into local BC or year 10000.
- **Unchanged:**
  - every comparison, state, expiry and age;
  - the one clock;
  - an infinity expiry stays `current`, and nulls mean no representable finite time (never expired, unlimited or
    ready);
  - `secondsSinceSeen` is null with an unrepresentable or future time;
  - privacy, the page shape, and no dropped row or `mine`.
