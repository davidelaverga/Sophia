## Reading inherited evidence safely

The retained registers include earlier boot experiments, prior model catalog snapshots and source-only donor tests. Those are useful for provenance and explanations, not commands to recreate achieved work. Current model routes, priced research behavior and source readers come from the actual M02/M03 implementation and its current author handoff.

The lead's semantic progress review is separate from Paperclip's liveness/recovery checks. Its triggers are owned by the selected work controller; an old suggestion of a five-minute application job does not install a competing scheduler or grant a standing mandate.

Source reuse preserves licenses and notices. Provider docs are referenced and summarized, not bundled as copied documentation. The older packs remain in the repository for historical audit; the normative continuation requirements live in this pack.
