## Inputs and limits

The cumulative v0.4 tree was matched to the repository by Git tree hash. v0.3 is covered through that cumulative successor and explicitly superseded, not installed a second time. The SCM pack's detailed contracts/roles/acceptance remain local with the current baseline/ownership corrections. The October1 overlay's work lanes and frontend implementation are folded in. Active feature PR evidence controls what is already authored; this pack is not a fresh production audit.

This table is not a claim of exhaustive line-by-line formal equivalence. Detailed source-bound transport/rendering inputs, original decision dispositions and required goal acceptance are included; the current source/generated contracts win when historical illustrative fields disagree. Any newly discovered unmapped acceptance requirement becomes an explicit correction to this pack, not silent scope loss.
