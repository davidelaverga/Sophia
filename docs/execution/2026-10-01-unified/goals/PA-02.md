## Goal sessions

### PA-02.G1 — Build private inspection and redaction

Reuse data-only artifact view in the personal audience. Show source/coverage/attachments and distinguish findings from inference. Let the owner remove one item and correct an interpretation without changing the original immutable version.

**Handback:** exact code/contract/evidence or a specific unmet boundary; report actual versus simulated behavior.

### PA-02.G2 — Materialize exact share preview

Create selected sanitized snapshot with destination, explicit attachment list and digest. Exclude hidden metadata, private paths/source bodies and unselected notes. No model rewrites between preview and approval.

**Handback:** exact code/contract/evidence or a specific unmet boundary; report actual versus simulated behavior.

### PA-02.G3 — Publish transactionally

Recheck same owner, current destination membership and policy, source eligibility and expected hash/revision. Commit approval/outbox, copy/verify staged bytes then expose one project contribution and receipt. Lost reply reconciles to same share.

**Handback:** exact code/contract/evidence or a specific unmet boundary; report actual versus simulated behavior.

### PA-02.G4 — Integrate mission use and withdrawal

Team can retrieve only the shared snapshot; treat it as evidence rather than accepted mission. Explicit updates make new versions. Withdrawal fences future use and derives cleanup; private erase and shared withdrawal remain separate.

**Handback:** exact code/contract/evidence or a specific unmet boundary; report actual versus simulated behavior.

### PA-02.G5 — Close one real contribution episode

Owner removes a sensitive item and shares a useful package; team uses it in a decision while unable to retrieve excluded material. Test stale preview, removed member and copy failure.

**Handback:** exact code/contract/evidence or a specific unmet boundary; report actual versus simulated behavior.

## Acceptance and adverse cases

| ID | Case | Required observation |
|---|---|---|
| PA02-T01 | Exact content review | Only inspected selected bytes and metadata reach the named workspace. |
| PA02-T02 | Bot attempts share | Connector credential cannot call publication, even with an approved field or copied owner ID. |
| PA02-T03 | Concurrent edit | Changed package/selection invalidates preview; stale approval cannot publish new unseen content. |
| PA02-T04 | Membership race | Owner removed between preview and commit cannot publish. |
| PA02-T05 | Copy failure | Partial object copy remains invisible; retry yields one complete contribution. |
| PA02-T06 | No live private link | Team cannot dereference shared record into unshared versions, raw paths, notes or personal message history. |
| PA02-T07 | Erase versus withdraw | Private erasure does not silently delete shared version; explicit withdrawal prevents new controlled retrieval. |
| PA02-T08 | Mission meaning | Sharing an older plan is not acceptance and cannot overwrite a newer mission decision. |
