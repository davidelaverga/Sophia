## Changes and checks

Name affected paths, schema/amendment IDs and removed duplicate machinery. Record each actual command, environment, exit code and evidence artifact. Distinguish synthetic/native/provider/hosted tests. Report baseline failures as such only after reproducing them on the actual base.

## Work and resource state

Record project/work/assignment/attempt IDs, current control generation, native session binding, outstanding requests/effects, source/candidate hashes, allowances consumed/uncertain/remaining and stop/recovery state. Sensitive values stay in private stores.

## Decisions and unresolved findings

List only decisions genuinely requiring an owner. Each finding names the actual source/version, observed behavior, impact, attempted remedy and next actor. Do not turn a missing prerequisite into an unlimited research task.

## Next bounded action
