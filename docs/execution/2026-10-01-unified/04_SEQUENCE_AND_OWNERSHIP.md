Claude Code is an implementation resource for either owner, not a global owner of every file. Codex supplies independent review and separately approved operational work. Routine code edits within an assigned scope do not need a new ceremony; effects that change environment, permissions, payer or scope do.

## Start now, activate only the relevant real capability

LFE-00 and SCM-00 share a compact baseline handback. They are not duplicate release campaigns. Luis can prepare gallery, editor, owner-action and private-package fixtures while the corresponding API work proceeds. Fixtures are labelled; live readiness comes only from the relevant actual crossing.

SCM-01 can perform a bounded source review without waiting for images, decks, personal space or all three owner resources. SCM-02's local adapter work can proceed independently. Their integrated peer episode joins at SCM-03. The current room remains usable during Paperclip outage.

PA-00 can qualify a harmless connector round-trip before the full personal UI is merged. PA-01 requires real owner-private persistence and message access, not a synthetic team project. PA-02 joins the private package and explicit sharing to the team source reader. Personal Companion generation is a distinct optional consumer, not a prerequisite for human review.

PA-03 browser/environment tasks require PA-02's output/authority boundaries. PA-04 cross-owner cooperation requires the private flow plus actual operational peer boundaries. Do not replace the first collection task with two generic parallel research Bots.

## Shared-file claims

Claim actual branch/worktree, source head, owned paths and exact integration counterpart before editing. One current writer owns each shared file or effect scope. Explicitly coordinate:

- `App.tsx`, `route.ts`, `useProjectRoute.ts`, report deep links and personal call retention.
- `StudioShell`, `SidePanel`, `CallSwitches`, dock/mini-dock, focus and keyboard ownership.
- A10/A11 and new amendments/migrations, generated contracts, `config/specialists.json`, runtime locks/digests.
- Source/byte storage and artifact readers shared by reports, images, prototypes and private packages.
- Private notification/audience policy; do not route personal jobs through the team event feed.

Use the current PR author until a real handoff; absence from main is not permission to recreate an active branch's implementation. Merge ancestry and source must be preserved deliberately. Scope an integration patch rather than copying arbitrary UI files.

## Definition of a useful session

Deliver one visible, tested slice or an exact boundary finding. Name what is fixture-ready, source-ready, integrated, hosted-verified and product-accepted. These are evidence categories, not five mandatory approval meetings. The LFE package shares its evidence with its parent product/SCM/PA goal; it does not create another scheduler or demand duplicate tests.

Use [working protocol](operations/WORKING_PROTOCOL.md), [handoff](operations/HANDOFF_TEMPLATE.md), and [goal launches](launch/INDEX.md). Stop at an actionable handback rather than keeping an agent running while waiting for an absent owner.
