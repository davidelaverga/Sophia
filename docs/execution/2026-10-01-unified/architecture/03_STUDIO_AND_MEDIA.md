# Studio, media and cross-feature interaction

## Preserve the implemented room

Converse uses the actual main composition: the room center holds Sophia, participants and dock; Chat and Brief are mounted tabs in a right-hand panel. Unsent text, manual brief edits and per-viewer focus survive switching. Explore and Build put the actual asset/source at the center; no older centered-chat restoration.

Server project state, viewer state and media state are independent. A new snapshot cannot erase a draft. A component unmount cannot cancel work. A participant's view change cannot move another participant or grant source-edit authority.

View opens an object locally. Discuss references it. Focus together changes shared focus only for people following. Change work admits an authorized operation against a real target. The host confirms each material effect before narration says it happened.

## One candidate through several views

Preview, Source, Diff, Sources and History refer to the selected exact source/version. New output is offered, not silently substituted while somebody reviews an older version. The last useful candidate remains visible during authorship, failure or conflict. Downloads verify the selected bytes/hash, not a changing latest URL.

Use the current report viewer and shared pure presentation helpers. A data-only Markdown view never becomes an arbitrary HTML execution context. Application preview requires an isolated origin and an explicit frame/selection contract; unembeddable third-party pages get an honest external route, not stripped security headers.

## Real media state

Continue raw LiveKit ↔ Gemini media bridging, admitted input-floor/exchange, observed playback generations, selected visual frames and correct speaker/inputMode attribution. Barge-in clears old audio, not unrelated background work. Stop Looking, Stop Speaking, End exchange, leave room, Hold/Stop work and disconnect resource are separate controls. Result completion does not reopen an ended voice exchange.

S2 discussion-following is opt-in, track-attributed and governed by current consent. No biometric inference, hidden microphone activation, default ambient transcript retention or retired Tone Scale. One participation decision is used only for the following lane; ordinary invoked voice remains direct Gemini. Test EN/IT/ES, quoted names, negation, overlap, numbers and correction.

## Keyboard, accessibility and mobile

Follow the real CONTRIBUTING contract. Typing a letter must not activate microphone/camera/screen sharing. Modal and hidden views do not compete for keys. Focus returns to a meaningful control after sheets close. Active sending, errors, mute/stop/leave remain reachable on phone overlays. Routine progress should not create a screen-reader announcement per event. Test zoom, coarse pointer, reduced motion, color-independent state and actual narrow layouts.

PR30's proposed cross-place call retention differs from main. Integrate it intentionally: hidden project keeps no key/attention ownership; switching to a different project ends the former call. Its privacy curtain is device UI, not universal revocation or permission to read private material in the room.

## Personal assistant surfaces

A personal import job and message thread use personal queries/caches/notice channels. Locking personal view clears/hides sensitive client material without claiming remote computation stopped. Do not narrate private Bot findings into shared audio or populate shared badges/search with their titles. Human publication creates a separate shared version. A later team Bot task uses the current team's scope, not the private import thread.
