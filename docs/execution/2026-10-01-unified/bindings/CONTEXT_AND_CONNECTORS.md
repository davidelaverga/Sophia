# Context packets, structured import and later connectors

Accepted mission/goal revisions, constraints and permissions are direct application state. Sources are immutable scoped evidence. Knowledge pages/wiki summaries are rebuildable projections with source and freshness. Do not introduce a second writable mission.md or import the old memory middleware as a prerequisite.

A ContextPacket names audience/project or personal owner, goal/attempt, accepted revisions, source/candidate hashes, active constraints/decisions, relevant bounded excerpts, open obligations, role procedure, resource envelope, missing coverage and eligibility revision. Give each packet a canonical digest. Direct current-state reads precede scoped search/read; native compaction/spill does not decide source eligibility.

The guide receives relevant direction/focus/required actions; the lead receives roadmap/current evidence and reservations; workers receive exact tasks/source; reviewers receive criteria/candidate/checks and uncertainty rather than a preferred verdict. Raw peer/history content stays untrusted data. Private and shared compilers have disjoint audience checks.

Selected exports, files and handoff bundles are valid import routes. Preserve author/time/source/version/extraction and missing grouping/attachments. Deduplicate within permitted scope without leaking another owner's existence. A reconstructed direction is a proposal, never an automatic overwrite. PA adds a knowledgeable assistant collector, not blanket reverse access to vendor Projects. Unsupported source access remains explicit.

Correction/Forget immediately narrows eligibility and invalidates dependent packets, summaries, claims and future resumed workers. Where Sophia controls the runtime, rebuild/stop before further affected inference. For external personal Bots show the limitation of already-copied provider context; fence tool reads/result acceptance and avoid a global erasure promise. Keep minimal non-content tombstones for old requests.

Maintain a source-linked repository map of actual entry points, checks and implementation/verification state. A filename tree is not proof of functionality. A next work brief must use at least one relevant accepted decision/lesson with its evidence. Preserve no-change conclusions. Procedural promotion is a later exact-version reviewed operation.

Later direct connectors begin with selected Notion input/publication, then scoped Supabase/Vercel read and effect operations. Use actual OAuth/resource grants and endpoint evidence; no inferred account ownership. A provider disconnection has an explicit freshness/failure state, not scraping or another-account fallback. Direct structured connectors and the optional personal-assistant path can coexist.

Export actual source, assets, versions, decisions, current task state, useful checks and unresolved effects, with omission/access coverage. Exclude raw private runtime logs, erased sources and unpublished personal packages. Test a fresh human engineer's takeover before calling the project portable.
