# Personal-assistant proposed contracts

These shapes describe server-side records and reviewed application design. They are not raw client authority. Fields such as owner, sender, audience, receipt, generation and confirmation come from authenticated server operations. JSON Schema cannot prove a caller is human or authorized; the service must derive/verify those facts.

No Bot-callable publication operation exists. The share shape is a human-only command/record binding. The first private message schema deliberately cannot target a project or another personal owner. PA-04 gets a separate reviewed project envelope using allowed recipient edges; do not simply relax the private enum.

The actual next OpenAPI amendment, database migration and supported request/response fields are authored in the target repository after refreshing current reservations. Passing these fixture checks is not database isolation, OAuth, provider execution or production acceptance.
