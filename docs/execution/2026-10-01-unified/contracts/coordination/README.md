# Coordination schemas

These are the retained, proposed contract schemas integrated into v2.0. They are not a deployed OpenAPI or migration. Bind them through the current application schema-generation path. Native provider/adapter field names come from the selected source, not these product envelopes. The application must enforce identity, revisions, current grants and authority in code/SQL; passing JSON Schema is not authorization.
