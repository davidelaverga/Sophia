# Skill — review an exact web candidate

Use only when the connection is qualified for the stated computer/network and the assignment permits it. Read the candidate URL/source marker, test-account role, viewport, journeys, expected behavior, allowed targets and prohibited effects. A private-network route depends on the enrolled device while it is in use.

Before each meaningful action inspect current page/window state; never reuse stale coordinates as if still valid. Perform the bounded journey without modifying production data or contacting third parties. Stop for login/MFA/CAPTCHA and actual native approval. Ask a useful question when the target is unclear.

Return each finding with candidate identity, steps, expected/observed behavior, reproduction result, timestamp and selected screenshot/log evidence. Separate observation from interpretation and untested claims. Use actual files/tool content; a local path alone is not delivery. Preserve privacy and hidden metadata rules on screenshots.

Read pending Sophia guidance before a new journey and submission. A failed journey is evidence, not a reason to bypass site security. Computer use complements executable tests; do not claim complete correctness. Submit a candidate through the approved private or explicitly project-scoped return path.
