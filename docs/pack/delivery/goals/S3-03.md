## Acceptance evidence

- A harder question obtains stronger judgment and routine continuation de-escalates within the existing grant.
- A changed profile produces an inspectable configuration receipt.
- One procedure improvement is promoted with evidence or rejected without loss of the baseline.

## Adverse checks

- More model calls are not described as independent verification.
- An aesthetically preferred result cannot erase failed acceptance criteria.
- Multiple calls to the same judge are not counted as independent expert votes.
