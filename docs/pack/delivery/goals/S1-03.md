## Work sequence

1. Boot the official profile in an isolated project container/home with outbound authenticated control and explicit readiness.
2. Bind public Agent create/resume and scoped setup to the command contract. Persist external correlation as a session extension event and reconcile it with native inbox/history.
3. Bridge durable session events separately from transient assistant chunks. Flush through the native checkpoint seam before durable-delivery receipts.
4. Implement Hold/Stop as domain fencing plus native cancellation and associated job settlement. Test role allowlists through ordinary tools and PTC.

## Acceptance evidence

- A live worker receives a mid-work steer at a supported boundary; later evidence distinguishes delivery from incorporation.
- A controlled restart reconstructs command/native correlation and outstanding work.
- A real Stop prevents new dispatch and candidate publication under the stopped epoch.

## Adverse checks

- Duplicate delivery does not repeat an admitted domain effect.
- A late peer message cannot revive a stopped task.
- A forbidden host tool remains forbidden inside a PTC program.

- Hold retains pending context without permitting a native wake or goal driver to execute it before an explicit valid Resume.

## Session and handback

Create the actual attempt binding at execution: goal ID, native session, owner, worktree/base commit, writable scope, runtime unit, existing authority and cumulative allowance. The brief is not a permission grant. Keep source and assignment identity in every handback. Use [SESSION_HANDOFF](../../templates/SESSION_HANDOFF.md); return commands actually run, exact result versions and limitations. A failed attempt remains part of this goal rather than disappearing when a new coding chat starts.
