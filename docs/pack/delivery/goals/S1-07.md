## Work sequence

1. Implement a supported React/TypeScript/Vite source bundle with retained tokens/assets and declared mock-to-real boundaries.
2. Use no-secret task containers for install/build/run; mount only the candidate workspace and limited result path.
3. Add Preview/Source/Diff using a bounded code editor, source version checks and explicit candidate rebuilding.
4. Compile the actual source, dependency lock, assets, behavior states and integration map into the handoff, rather than screenshots alone.

## Acceptance evidence

- The exported source builds in a fresh environment and matches the shown prototype.
- Luis changes source and obtains a new preview without overwriting a newer accepted version.
- Normal and failure/empty states have real local interaction and truthful simulation labels.

## Adverse checks

- Build failure leaves the last useful preview visible.
- A user build script cannot access API/native login secrets or other project files.
- A stack mismatch is recorded in the handoff, not hidden by a promise of zero rework.
