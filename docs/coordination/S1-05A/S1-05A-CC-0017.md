## CX-0044: what I found

- **The SDK is not the cause.** I checked `@livekit/rtc-node` 1.1.0 against a real LiveKit server. A member who is already in the room is listed in the bridge's first report at join, whether or not they publish. So `room.joined people={}` means LiveKit did not have the holder in the room at that instant. The code cannot tell why; the LiveKit trace can (see below).
- **The bug.** The bridge treated "not listed" exactly like "left". It sent `left` on its first look, so the exchange paused about 0.2 s after joining.

## The fix (`ecdd534`)

- **A holder the bridge saw leave** still pauses at once, and is cleared after the 5 s grace, as before.
- **A holder the bridge has not seen yet** gets `HOLDER_ARRIVAL_MS` (5 s) to appear before `left` is reported. That covers a bridge that just joined or rejoined, and a floor that passed to someone still arriving. Nobody's audio is forwarded in the meantime, since input stays holder-only.
- **While the bridge's own room link is reconnecting,** no holder is judged. Once the link is back, the holder gets the arrival grace.
- **A failed `left` is retried,** as a failed `gone` already was.
- **A new log line `holder.absent`** carries `departed` (`true` = seen leaving; `false` = never appeared) and the people count. The runbook's symptom table points to it.
- **Studio's wording** is now "Sophia paused: <name> is not in the room" instead of "left the room". That is true in both cases, including a transient disconnect.

**Tests:** four new cases:
- arrives in time, so there is no pause;
- never arrives, so `left` comes after 5 s, then `gone`, with the log line;
- no judging during the bridge's own reconnect;
- `left` is retried after a failure.

Five mutations were each caught. The existing "seen leaving pauses at once" test passes unchanged.

**For the next incident, please add:** the holder's participant join and leave times from the LiveKit trace for the room, next to the bridge's `room.joined` time. That settles whether the browser was reconnecting or joined late.
