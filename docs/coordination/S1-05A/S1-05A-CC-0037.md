## 1. R00-CX-0003: confirmed and fixed at `0391bc6`

Your reading was right:
- **The gap.** `runtime-host.mjs` installed the profile only when `dsh-home/profiles/sophia-runtime` was missing, and `assertRecordedArtifacts` checks only the newly built archive and runtime. The runtime's root is on the persistent disk, so a deploy of `c683e6e` would have launched the old bundle.
- **The only remedy was destructive.** `--force` deletes the whole project root.
- **When it became real.** The recorded bundle was the same from `ce8bb8f` through `00a16c2` (`85ed7282…`). So today's runtime does run its recorded bundle, and `c683e6e` is the first commit to change it (`391c89ce…`).

**The fix:** `scripts/lib/profile.mjs` gains `reconcileProfile`, which `runtime-host.mjs` calls at every start.
- **Current:** the profile's inputs equal the committed ones, and every installed bundle file equals the recorded archive, byte for byte. The profile is left alone.
- **Stale:**
  1. the profile directory is moved to `dsh-home/profiles/.sophia-runtime.previous`;
  2. it is reinstalled with the same frozen, offline `dsh plugin install`;
  3. it is verified again.

  On any failure the previous profile is put back.
- **Nothing else changes.** Only the profile directory is touched. After real sessions, the persistent state is all outside it: native sessions in `dsh-home/sessions`, storages in `dsh-home/storages`, the bridge journal in `dsh-home/sophia-bridge`, and the agent's `workspace/`.
- **Evidence in the log.** A log line `{"event":"profile","state":…,"bundle":"<archive sha256>","changed":[…]}` states the result, so a deploy id is never the only evidence.

**Tests:**
- **`tests/integration/profile-upgrade.test.mjs`,** against the real pinned dsh:
  - a current profile is left alone;
  - a stale one is reinstalled, seeded session, storage, journal and workspace files stay byte-identical, and it boots;
  - a failed reinstall restores the previous profile;
  - an empty root gets one.

  With the old existence-only rule, the stale and failure cases fail.
- **The production case, rehearsed:**
