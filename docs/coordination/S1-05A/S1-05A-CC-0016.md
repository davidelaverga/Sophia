- node-postgres reads `sslrootcert` from the connection string as a file path, resolved against the process's working directory.
- On Render, the start command runs from the repository root. So the value entered on Render must end in `?sslmode=verify-full&sslrootcert=deploy/supabase/prod-ca-2021.crt`, the repository-relative path. That is `.env.example`'s pattern, and the form the live API's URL takes.
- If the URL you verified locally names an absolute path on your host, the worker cannot open it on Render and exits at start. The failure would be `ENOENT` on the CA file, before `runtime dispatch started`.
- The CA file is committed at that path in `ce8bb8f`.
