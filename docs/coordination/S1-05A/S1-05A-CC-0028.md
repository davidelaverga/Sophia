## Where the invariant holds

- **After M2.** Every guest token the API mints is preceded, in the same request, by `guest_token_minting()`. That call checks the admission under the project lock and stamps the fence. The fence runs 630 s from that stamp, so it outlives the token's 600 s. That is the bound CX-0048 asks for, and it now holds for the deployed API.
- **Between M1 and M2** (minutes), the old API stamps only at the request. CX-0048's residual applies only inside that window: a guest token request whose LiveKit presence call hangs for more than about 25 s. Production has no fence at all today.

## What else 0016 changes (Codex's review of aba31d5)

- **Results under current authority.** A native result is captured only if its turn ran under the goal's current epoch. A turn from before a Hold, replayed after a Resume, stays withheld.
- **The command poll.** It reads the queue only as the lease holder, under the instance row's lock.
- **Decisions in a manifest.** A draft_brief manifest carries only accepted decisions from eligible project sources, each recorded as a dependency. No decisions exist yet.
- **The removal watch.** A removal keeps watch for 630 s.
