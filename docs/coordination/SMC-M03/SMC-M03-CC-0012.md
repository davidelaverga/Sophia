### What changed since `4bd6c0f`

The details are in SMC-M03.md §29 to §31 and in the contract binding's rows dated 2026-10-02.

- **M03-RF-0017 (bridge, 0035).**
  - When the room did not hear a notice, its readers' delivery is recorded at once; a later retry the room hears adds "heard". 0035 now keeps the union of the records (heard once heard, the largest count). It is amended in place because it is unreleased.
  - Recording stops the API listing a result, so the bridge keeps what it still owes: voice retries for listeners, and text retries for readers whose notice failed (in an all-text room, or in a room that heard it, which is never told again).
  - A close waits at most 3 s for deliveries in flight. A session that replaces a lost one on the same exchange receives what was owed, what was in flight, any unrecorded announcement and what was already delivered, and announces nothing until it has them.
  - The bridge no longer holds a live room's update while another session closes.
- **M03-RF-0018 (kernel identity).** The identity covers every module the kernel runs and, for each judging package, its version and the bytes of the files a judgement loads. These are pdf.js's main and worker builds, and the `@napi-rs/canvas` files pdf.js loads in Node, which the review found. Three tests hold the lists:
  - a static closure that fails on any loader it cannot follow until that loader is reviewed;
  - a runtime record of what a judgement loads;
  - the identity changing with each file and version.
- **M03-RF-0019 (probe).**
  - A check that was not performed fails ("not run").
  - The checks inside run through `bin/confine-chromium` itself. They add a network-namespace check and the job's environment.
  - Only EACCES or EPERM shows a path closed, and only an immediate refusal shows a host closed.
  - Named paths must be files or directories the probe itself can read (the positive control). Directories are tried entry by entry, with links followed.
  - The command line is strict: exit 2 and nothing run on anything it does not understand. It also works through a link.
- **M03-RF-0020 (Studio).** Open names the primary file's version and format, the same file Download saves. A link to a version the viewer's cached list lacks reads the list again once before saying it is not available.
