- **Only live work is revoked.** A withdrawal revokes only research that is still under way: `research_revoke_source` (0028) selects jobs in `pending`, `running` or `outcome_unknown`. A design or review is revoked only while under way, too (0041).

## 5. Rollback

- **Guide:** unset `SOPHIA_GUIDE_VERSION` (back to v1.2, byte-identical declarations).
- **HTML off without a rollback:** revoke the `png` runner, or run a runtime without the designer: admission then refuses HTML (`html_unavailable`), Markdown is offered; a design in flight is ended by Stop.
- **Runtime:** as SMC-M02-CC-0003 §3: set `SOPHIA_RUNTIME_TOKEN` back to the m03 capability and redeploy the previous commit on the same root; `runtime-host` reconciles the profile back. First the same read-only check as P4 on the new unit: live design, review or research on it is ended by its own Stop; its terminal bindings are recorded and left as they are (a completed report is not rebuilt).
- **Schema:** forward-only. 0038–0041 and 0043 add tables and replace functions; a revert is a new migration restoring earlier function bodies, which this PR does not prepare.
