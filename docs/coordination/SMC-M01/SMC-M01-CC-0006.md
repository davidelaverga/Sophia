## What changed since CC-0005

All four fixes answer the third Codex GitHub review of #18 (review 5346681863). Each has a test that fails before its fix.

1. **A replacement must still replace (P1).** Two proposals naming the same accepted decision could both be accepted. `mission_accept` now answers a stale conflict when the named decision was already replaced.
2. **Freshness during the guide's own writes (P2).** An external change that landed while the model's own write was in flight used to be hidden by the newer receipt. `GuideContext` now keeps the revision of the model's last full read and the set of its own write receipts. Any other revision is flagged.
3. **Retries reuse their key (P2).** After an unconfirmed correction, the Studio offered a fresh save, which minted a new key. Now it offers only "Not confirmed: try again", which reuses the key. The same rule covers adding a note, forgetting one and deciding a proposal.
4. **Corrections keep their links (P2).** A correction now carries over the corrected note's related entry, goal and decision, unless it names its own.
